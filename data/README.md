# data/

Les données de GRAVITY CARE sont **simulées**. Elles sont produites par le code du backend :

- `backend/app/simulate.py` : trois astronautes fictifs, 30 jours, graines fixes (reproductible)
- `backend/app/sensor_simulator.py` : simulateur de capteurs qui envoie les mesures à l'API

Aucune donnée réelle d'astronaute n'est utilisée.
